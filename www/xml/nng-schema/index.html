XML namespace: nng

This is the URL for the namespace used in nng, my site generator.

This namespace is only used for tags that occur within the content, not in the template. These are snippet and refer.

Snippets

nng allows recording “snippets”, which are blocks of HTML, and then “referring” to them, which both copies the inner text of the snippet and provides a link to its source.

The below XML:

<page xmlns:nng='https://needleful.net/xml/nng-schema'>
	<!--making a snippet-->
	<nng:snippet name='example'>
		<p>This is an example snippet!</p>
	<\nng:snippet>

	<!--referring to it-->
	<nng:refer name='example'>
<\>

Transforms into something like the following HTML:

<!--The snippet source-->
<div id='example' class='snippet-block'>
	<p>This is an example snippet!</p>
<\div>

<!--The Referer-->
<div id='example' class='snippet-block'>
	<p>This is an example snippet!</p>
	<a class='snippet-link' href='/source.html#example'>[Source]<\a>
<\div>
